 # RW MVP — Out of Scope

အောက်ပါ feature များသည် ၂ ရက် MVP ထဲတွင် မပါ။ နောက်အဆင့်တွင် လိုအပ်ချက်နှင့် device test ရလဒ်ပေါ်မူတည်ပြီး ပြန်ဦးစားပေးမည်။

| Feature | MVP မှာ မပါဝင်သည့်အရာ |
| --- | --- |
| Recording နှင့် history | Video/audio သိမ်းခြင်း၊ playback၊ timeline၊ cloud archive |
| Snapshot | ဓာတ်ပုံရိုက်သိမ်းခြင်း၊ download၊ share |
| AI | လူ/ပစ္စည်း/လှုပ်ရှားမှု သိရှိခြင်း၊ AI alert၊ AI summary |
| Notifications | Push၊ SMS၊ email၊ motion alert |
| Accounts | Sign-up၊ login၊ password၊ profile၊ account-based device management |
| Multiple devices | Camera ၂ လုံးနှင့်အထက်၊ viewer ၂ ဦးနှင့်အထက်၊ room list |
| Continuous intercom | Viewer microphone ကို အမြဲဖွင့်ထားခြင်း၊ group talk၊ voice message သိမ်းခြင်း |
| Advanced alarms | Alarm schedule၊ အသံရွေးချယ်ခြင်း၊ app မဖွင့်ထားသော device သို့ push alarm ပို့ခြင်း |
| Remote controls | Camera လှည့်/zoom/flash ပြောင်းခြင်း၊ remote mic control |
| Always-on mobile capture | Phone lock ဖြစ်နေစဉ် သို့မဟုတ် browser background ရှိစဉ် အမြဲ capture လုပ်ပေးရန် အာမခံခြင်း၊ native app |
| Long-term pairing | Camera/server restart နောက် အလိုအလျောက် session ပြန်ဆက်ခြင်း၊ viewer device အသစ်သို့ pairing လွှဲခြင်း |
| Advanced operations | Admin dashboard၊ usage analytics၊ billing၊ quality presets၊ bandwidth reporting |

MVP တွင် ပါဝင်မည့် feature နှင့် acceptance criteria များကို [requirements.md](requirements.md) တွင် ဖော်ပြထားသည်။
